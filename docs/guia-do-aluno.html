0/6

Antes de começar

Você precisa ter

  • Uma VPS Ubuntu 22.04 ou 24.04 limpa.
  • Seu domínio adicionado à Cloudflare e já ativo.
  • Uma conta Tailscale para acessar os painéis privados.

Você pode pular

Claude, OpenAI e Telegram são opcionais. Se não tiver uma credencial agora, pressione Enter. Você configura depois.

1/6

Instale a fundação

No terminal da VPS, cole e pressione Enter:

bash <(curl -fsSL https://get.motobot.com.br)

O wizard faz as perguntas primeiro e trabalha sozinho depois. Quando uma senha ou token for digitado, você verá asteriscos: isso confirma que a colagem entrou sem revelar o valor.

2/6

Responda só o essencial

  1. Nome do projetoUse o nome da sua startup ou do cliente.
  2. Domínio principalExemplo: minhamarca.com.br.
  3. E-mailUse um e-mail seu para HTTPS e os painéis.
  4. Token CloudflareCrie um token com Zone → DNS → Edit, limitado ao domínio escolhido.
  5. Auth key do TailscaleCrie uma chave de uso único e não efêmera. Ela deixa os painéis privados.

O token de DNS da Cloudflare serve apenas para criar subdomínios. Ele não é o token do R2 para backup.

3/6

O que fica pronto

Base técnica

Docker Swarm, Traefik, HTTPS, PostgreSQL com pgvector e Redis.

Gestão privada

Portainer e Beszel acessíveis somente dentro da sua Tailnet.

Proteção

Secrets, backup local diário e teste de saúde da base.

4/6

Entre nos painéis

PORTAINER

Organize seus containers

Abra o endereço mostrado no fim da instalação, com o Tailscale conectado. Crie seu usuário e senha no primeiro acesso.

Se a tela pedir um setup token ou ele tiver expirado, rode:

motobase portainer-token

Copie o token mostrado e cole na tela. Ele não apaga sua VPS.

BESZEL

Acompanhe a saúde da VPS

Abra o endereço do monitor com o Tailscale conectado. Para ver o usuário e a senha, rode:

motobase acessos

O painel mostra CPU, memória, disco, rede e containers.

5/6

Você não instala a fundação de novo. Use o mesmo comando para abrir o menu:

bash <(curl -fsSL https://get.motobot.com.br)

6/6

Se algo parar

Regra simples: rode o mesmo comando de novo.

O wizard reaproveita o que já foi instalado. Não precisa apagar nada nem começar a VPS do zero.

bash <(curl -fsSL https://get.motobot.com.br)

Para conferir a saúde da base depois:
